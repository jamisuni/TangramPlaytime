# CHG-002 — The launcher icon and the store icon are in scope

## Change
REQ-048 Rules, new bullet after "Store name": **"The app has a launcher
icon; the store icon is made from it. The icon is chosen by the owner from
options proposed to him (SRC-016, 2026-10-05: option A, a coloured square,
kept as design input DI-9); it shows no text and no third-party mark."**
Acceptance, new **A4** — "The installed app shows a launcher icon that
matches the store icon; the icon contains no text."

## Reason
The first build found the icon undeclared (review F35) and the owner
decided who makes it ("AI proposes, you pick") and which one ("A: coloured
square"). The second build should not rediscover the gap or redraw the
choice; the owner's pick is a design input, the obligation is a rule.

## Impact
REQ-048 gains A4; `design-inputs.md` DI-9 (`Spec/icon/option-A-*`) is the
asset; build-side a trivial task in the #Release WO. No other REQ changes.

**Applied 2026-10-11** (owner acceptance in chat; REQ-048 re-signed, see
CHG-001).
