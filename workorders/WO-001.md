# WO-001 — #Locking: the one lock rule in `:kernel` behind `ILockEngine`

**Status:** Done (closed 2026-10-11 13:04, G4 under governance row 9 `ai`)  ·  **Mode:** Full (b)
**Kicked off by:** Jami / 2026-10-11 (KICKOFF.md paste-in brief)  ·  **Plan approved:** 2026-10-11 (G3 under governance row 7 `ai`; plan-check GREEN; plan review 0 B / 2 S)

## Goal

Build the geometry kernel every later WO leans on: the TYPE-001 piece shapes,
the TYPE-003 turn and mirror, and the TYPE-004 lock search (anchors, candidate
translations, validity, scoring) as the `ILockEngine` implementation in
`:kernel` — the prototype's `findLock` / `validAt` / `anchors` ported per
ADR-001, following the TYPE-004 text where the prototype differs
(`design-inputs.md` §2 item 3). Pure JVM; no UI. First in the owner's order
because #Solving (WO-003), #Browsing (WO-004) and #DevTools (WO-005) all ask
this seam.

## Scope  *(the traceability anchor)*

- **Implements features:** #AnchorLock, #GoHome, #SolvedCheck (REQ-019 A1..A4,
  REQ-020 A1, REQ-022 A1) — plus the value rules TYPE-001, TYPE-003,
  TYPE-004 implemented once in `:kernel` (D1 value-rule exception,
  architecture.md §1 note, G-04). Code home: `kernel/` (build-map.md
  `#Locking`, `#SolvedCheck` and `(kernel)` rows).
- **Governed interfaces touched:** `ILockEngine` (**implements**, notify
  tier; every member is implemented — `outlineCorners`, `vertices`,
  `findLock`, `tryTurnInPlace`, `tryMirrorInPlace`, `stillValid`, `isSolved`
  — because the class must be complete, but acceptance coverage for the
  members that serve REQ-016/017/018/021/025/051 arrives with those REQs'
  WOs). Contract types of `Types.kt` (**consumes**). Its shape may change: a
  notify-tier change is logged as a `contract-delta` and summarised below.
- **Out of scope:** every screen and gesture (#Solving, WO-003); the landing
  preview drawing (REQ-021, UI); the corner pulse (REQ-051); puzzle loading
  and ordering (#Content, WO-002); persistence (WO-004); TYPE-005/006/007
  rules (later WOs in `:kernel`); the exact a + b√2 arithmetic of the Python
  tools (stays in `tools/`, ADR-001).
