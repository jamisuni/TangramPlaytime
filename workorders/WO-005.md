# WO-005 — #DevTools: the passcode-protected solution reveal, in debug builds only

**Status:** Done (closed 2026-10-17, G4 under governance row 9)  ·  **Mode:** Light
**Kicked off by:** Jami / 2026-10-17 (KICKOFF.md paste-in brief)  ·  **Plan approved:** 2026-10-17 10:23 (G3 under governance row 7 `ai`; plan-check GREEN; plan review 0 B / 3 S)

## Goal

Give the owner the testing aid REQ-046 asks for: a DEV button on the Play
screen that asks for a passcode, then shows every piece's solution position
on the silhouette or solves the open puzzle at once, so that every puzzle of
the library can be confirmed solvable (REQ-046 rationale, REQ-007). The aid
exists only in the `debug` build type (`play/src/debug`, G-08 / O-08) and is
drawn on the WO-004 Play screen: the overlay stays on while the player
browses, "solve now" goes through `PlayController` and `Persistence` like any
other solve, and the DEV button takes a place in the S-22 touch order. Fifth
in the owner's order (`build-map.md` §2).

- **Implements features:** #SolutionReveal (REQ-046 A1..A4). Code home: `play/` (`src/debug`) — `build-map.md` `#DevTools` row; #SolutionReveal inherits it.

## Constraints & notes

**Questions the plan must settle** (the planner's seams; each answer that is a reading no REQ fixes becomes a `decisions.md` row through the orchestrator):

1. **The debug-only seam (G-08, O-08, O-06).** The aid's code lives in `play/src/debug/`; nothing in `src/main` references it; the release APK contains no DEV button, no passcode and no solution overlay. The release build is not minified (no `isMinifyEnabled` in the build files), so whatever `src/main` holds ships. State how the debug source set reaches the Play screen and the controller — any hook in `src/main` must name REQ-046 (D3), carry no aid text, passcode or drawing, and be harmless when empty — and where the aid's strings live (O-06: `:app` resources; G-08: no passcode text in the release APK). 2. **"Solve this puzzle now" (A3).** Through `PlayController` and `Persistence`: the puzzle ends Solved, the solved picture shows, the best time stays empty, the save is the ordinary FIFO save. State which TYPE-006 transitions the aid performs and whether they are the locked ones (In progress → Solved when the last piece locks) or the draft's (New or In progress → Solved), and therefore whether REQ-046.A3 is `implemented (unverified)` for `chg-draft-type006-missing-transitions.md`.
